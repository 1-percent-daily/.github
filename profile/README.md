## What it is

A goal app for people building startups on the side. Set one money goal,
pick your top 3 priorities each day, commit to 3 results a week, and see
which of your projects actually pay off.

## What it solves

Side projects drift when nothing measures them. 1% Daily keeps every day
tied to one number, so small progress adds up instead of getting lost.
